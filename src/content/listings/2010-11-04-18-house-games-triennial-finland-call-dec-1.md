The next House Games triennial will be held in March 2011. This event takes
place in a standard Finnish apartment which maintains its function as a
home, while serving as an alternative exhibition outlet.
If you are interested in submitting a project proposal for the next House
Games exhibition, please send a free-form application including a project
description, and 3-5 (project related) images (92dpi min10 x 15cm) to :
housegames.info@gmail.com

Project proposals must be submitted by December 1st 2010.
Selected participants will be contacted in January 2011.

Applications are accepted in English, French or Finnish.

More information about House Games at : www.housegames.fi

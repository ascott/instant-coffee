Arnica Artist Run Centre
www.arnica.ca

On February 28th, Arnica Artist Run Centre in collaboration with Kamloops 
Printmakers Society present the 2014 International Print Exchange. Artist from 
around the world were invited to submit an edition of twelve artworks created 
using traditional printmaking techniques. Each artist will have one copy of their 
work on display at Arnica, one copy kept as part of the Kamloops Printmakers 
permanent collection, and receive one copy from ten other participating artists.

The exhibition runs from February 28th, to April 12th in Arnica Artist Run Centre 
at 7 Seymour St West, the Old Courthouse Cultural Centre. There will be an 
opening reception on Friday February 28th at 7pm.

Studiostone: Work Space & Workshops - Vancouver

Studiostone is a private run studio space dedicated to working with stone.
Fully equipped for hand and power tool use, there are currently 8 artists
completing stone sculpture projects out of this facility. The studio is
open to accepting artists interested in working in stone for short or long
term. There are also workshops offered to the public for learning stone
carving techniques. For more information please view the web site
www.studiostone.ca

January 2009 Stone Carving Workshops:

1. January 20th, 2009 Introductory Limestone Carving: Tuesday Evenings,
7:00 - 9:30 pm. 8 weeks
Carve a stone sculpture using hand and pneumatic tools. Limestone is a
medium hard stone and uses a different set of tools and techniques than
soft stone carving. It is also a good starting point for anyone interested
in carving marble or harder stones. 50 lb Stone and tools provided. Class
size is limited.

2. January 21st, 2009 Introductory Alabaster / Soapstone Carving:
Wednesday Evenings, 7:00 - 9:30 pm. 8 weeks
This class uses hand tools only from roughing out to finishing the
sculpture. Alabaster and Soapstone are softer stones and easier to begin
with. 30 lb Stone and tools are provided. Class size is limited.

See web site: www.studiostone.ca for details and registration forms.
